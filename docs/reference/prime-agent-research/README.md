# Prime Agent research material

This directory preserves external research into Prime Agent and its recursive-language-model (RLM), IPython, and continual-harness concepts. It may inform future product decisions, but it does not define Intention Relay architecture, milestones, or implementation scope.

## Contents

- [`prime-agent-runtime-reference.md`](prime-agent-runtime-reference.md): reference overview of Prime Agent's runtime, RLM, persistent IPython, agent lifecycle, skills, and harness.
- [`rlm-ipython-harness-integration-analysis.md`](rlm-ipython-harness-integration-analysis.md): analysis of how corresponding capabilities could fit Intention Relay's Rust-owned architecture.

The active rewrite reference is [`../../intention-relay/`](../../intention-relay/README.md). Architecture decisions remain authoritative only when explicitly adopted there or in a subsequent approved decision document.
