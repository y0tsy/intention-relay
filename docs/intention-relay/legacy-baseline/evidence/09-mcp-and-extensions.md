# MCP and extensions evidence

## Proved UI capability

`McpStatusWidget → mcpService.getMcpStatus → gateway.getMcpStatus → get_mcp_status` displays current MCP status.

## UI-mediated agent extension behavior

The generic configuration editor can persist MCP, skill and sub-agent policy fields. The runtime behavior report documents which facilities are built during application/agent initialization and become visible through a chat-mediated tool run.

## Excluded

No active frontend UI was found for MCP server create/edit/connect/disconnect/refresh or skill discovery/toggle. These are not current frontend features under this audit rule.
